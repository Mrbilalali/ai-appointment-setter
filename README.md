# AI Appointment Setter — Interactive Demo

An interactive, scripted simulation showing how an AI appointment setter books an appointment for a fictional beauty salon ("Glow Studio") — pick a service, pick a day and time, confirm, and see the booking confirmed in under a minute.

No real booking, call, or message is made. All data in the demo is fictional.
